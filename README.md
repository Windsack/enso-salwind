# Wind on Sal and ENSO

[Deutsch](README_DE.md)

Matthias Baier · Amílcar Cabral Airport (GVAC), Cabo Verde

This project examines how wind speed and direction at Sal Airport differ
between El Niño and neutral conditions. It uses archived airport weather
reports and the NOAA Relative Oceanic Niño Index (RONI). Supplementary
analyses include La Niña, complete-winter permutation tests and a
regression on continuous RONI.

## Reproduction

- [Public reproduction package, November 2026, version 1](https://sal.mbaier.com/enso/downloads/gvac_enso_reproduction_2026-11_public_v1.tar.gz)
- [DJF supplementary analyses, reproduction v1](https://github.com/Windsack/enso-salwind/releases/tag/djf-reproduction-v1)

The public package reproduces the calendar-month and three-month
comparisons and Figures 1 and S1 from the supplied monthly data.
The DJF supplement reproduces the three-phase analysis, the pooled
reference comparison, the winter-level permutation tests and the RONI
regression with its slope interval. Both packages include instructions.

## Winter 2026/27

The analysis plan specifies how December 2026 through February 2027 will
be compared with the historical neutral reference. The accompanying note
explains how to interpret the result for a single winter.
