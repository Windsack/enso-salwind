# Wind on Sal and ENSO

Matthias Baier · Amílcar Cabral Airport (GVAC), Cabo Verde

This project examines how wind speed and direction at Sal Airport differ
between El Niño and neutral conditions. It uses archived airport weather
reports and the NOAA Relative Oceanic Niño Index.

- [Study in English](https://sal.mbaier.com/enso/en.html)
- [Studie auf Deutsch](https://sal.mbaier.com/enso/de.html)
- [Wind statistics for sailors, kitesurfers and windsurfers](https://sal.mbaier.com/enso/harrys-point-wind.html)
- [Public reproduction package, November 2026, version 1](https://sal.mbaier.com/enso/downloads/gvac_enso_reproduction_2026-11_public_v1.tar.gz)

## Winter 2026/27

The plan specifies how December 2026 through February 2027 will be
compared with the historical neutral reference. The accompanying note
explains how to interpret the result for a single winter. Both documents
are in German.
